# Prompt library

Copy a prompt, fill the `[brackets]`, paste. All prompts assume the agent can read this repo (or you've pasted the brand tokens). Each file follows the advice in that vendor's own docs (see [chapter 8](../docs/08-prompting-ai.md)).

| File | Tool | Use for |
|---|---|---|
| [`claude.md`](claude.md) | Claude Code / Claude | Full video from brief; fixing stiffness |
| [`openai.md`](openai.md) | Codex / GPT | Full video; reference-driven style |
| [`gemini.md`](gemini.md) | Gemini (CLI / API / AI Studio) | Full video; long context with references |
| [`grok.md`](grok.md) | Grok Build / Grok | Full video; fast iteration loop |
| [`cursor.md`](cursor.md) | Cursor Agent | Scene edits with @ files and screenshots |
| [`shared-snippets.md`](shared-snippets.md) | Any | Paste-in blocks: life kit, QA, feedback, style materials |

**Golden rules for every prompt:** one job per video · format first · materials, not adjectives · tokens only · storyboard → stills → render · never invent facts.
