# Publish checklist

- [ ] Final MP4: H.264, yuv420p, 30 fps, correct size (1080x1920 for Reels/TikTok/Shorts)
- [ ] Watched once full-screen on a phone, muted and unmuted
- [ ] Facts double-checked; sources in the caption or description where useful
- [ ] Music/sounds you have rights to (or generated in code)
- [ ] First second shows the topic (no slow logo intro)
- [ ] Caption/description and alt text written; hashtags only if relevant
- [ ] Platform AI-content labels applied if the platform's rules require them for your content
- [ ] Project archived: source, tokens, `PROGRESS.md`, final render, and the prompt used
- [ ] Anything new you learned added to `library/` or `library/CHECKS.md`
