# New project checklist

- [ ] One-sentence job of the video written down ("After watching, the viewer…")
- [ ] Format chosen: size, fps (30), length, platform
- [ ] Brand tokens exist (or copy `tokens/` and edit) → `node scripts/build-tokens.mjs`
- [ ] Brief (`brief.md`) and 5-7 beat storyboard written and approved
- [ ] Stack chosen: HTML+GSAP (web/learning) or Remotion (video) — see [chapter 5](../docs/05-code-types.md)
- [ ] `git init` and first commit; `PROGRESS.md` created
- [ ] `library/README.md` and `library/CHECKS.md` read; parts to reuse listed
- [ ] Facts in the script have sources (or are labelled as illustrative)
