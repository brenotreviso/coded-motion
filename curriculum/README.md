# 6-week curriculum

For complete beginners. About 3-4 hours a week: one **lesson** (read + try), one **small project**, one **checklist** to finish the week. Every week builds on the last; by week 6 you direct an AI agent to make a branded short video and you can check its work.

| Week | Theme | Project | Guide chapters |
|---|---|---|---|
| [1](week-1.md) | Your first animation: HTML, SVG and a GSAP tween | A dot that says hello | 0, 5, 6 |
| [2](week-2.md) | Easing and timing | Three balls with three personalities | 4 (timing, easing, springs) |
| [3](week-3.md) | Arcs, anchors, squash & follow-through | A bouncing lantern | 4 (arcs, anchors, squash, follow-through) |
| [4](week-4.md) | Brand tokens, text and a living character | A 10-second branded title card | 2, 3, 4 (layering, staging) |
| [5](week-5.md) | Remotion and the video pipeline | Your first MP4 | 7 |
| [6](week-6.md) | Directing an AI agent + final project | A 15-20 s reel made with an agent | 1, 8, 10, 11 |

**What you need:** a computer, Chrome, [VS Code](https://code.visualstudio.com/) (free) and, from week 5, [Node.js](https://nodejs.org/) (LTS). No paid tools are required. An AI coding agent is optional until week 6.

**How to use a week:** read the lesson top to bottom and type the code yourself (don't paste). Then do the project. Then tick the checklist; anything you can't tick, redo before moving on.

**For teachers:** each project has a clear "done when". Ask students to hand in the HTML file + a screen recording (or contact sheet) + their ticked checklist.
