# Examples

Ten small pages. Each one shows a single idea. **Open the live demo** plays it in your browser. **View source on GitHub** opens the original file (`examples/html/` in the project), which is the file you edit if you [download the project](00-start-here.md#how-to-use-this-guide).

| Demo | What you will see | |
|---|---|---|
| **00 · Hello GSAP** | One apricot dot moves across the page. A tween is one animation from here to there. | [Open the live demo](examples/00-hello-gsap.html) · [View source on GitHub](https://github.com/brenotreviso/coded-motion/blob/main/examples/html/00-hello-gsap.html) |
| **01 · Easing** | Nine balls travel the same distance in the same time. Only the speed curve changes. | [Open the live demo](examples/01-easing.html) · [View source on GitHub](https://github.com/brenotreviso/coded-motion/blob/main/examples/html/01-easing.html) |
| **02 · Arcs** | The same jump, once in a straight line and once on a curve. | [Open the live demo](examples/02-arcs.html) · [View source on GitHub](https://github.com/brenotreviso/coded-motion/blob/main/examples/html/02-arcs.html) |
| **03 · Anchor point** | The same swing around three pins. Only one hangs like a real lantern. | [Open the live demo](examples/03-transform-origin.html) · [View source on GitHub](https://github.com/brenotreviso/coded-motion/blob/main/examples/html/03-transform-origin.html) |
| **04 · Motion blur** | A fast dot with no blur, with blended in-between frames, and with a stretch along its path. | [Open the live demo](examples/04-motion-blur.html) · [View source on GitHub](https://github.com/brenotreviso/coded-motion/blob/main/examples/html/04-motion-blur.html) |
| **05 · Squash and stretch** | A blob stretches as it falls, squashes when it lands, then springs back. | [Open the live demo](examples/05-squash-stretch.html) · [View source on GitHub](https://github.com/brenotreviso/coded-motion/blob/main/examples/html/05-squash-stretch.html) |
| **06 · Text reveal** | Words rise in one after another, then each word lights up like a karaoke caption. | [Open the live demo](examples/06-text-reveal.html) · [View source on GitHub](https://github.com/brenotreviso/coded-motion/blob/main/examples/html/06-text-reveal.html) |
| **07 · Breathing idle** | The lantern character breathes, blinks, floats, and its flame lags behind. | [Open the live demo](examples/07-breathing-idle.html) · [View source on GitHub](https://github.com/brenotreviso/coded-motion/blob/main/examples/html/07-breathing-idle.html) |
| **08 · Frame render** | A sunrise plays in the browser. The same page can also be saved as video frames. | [Open the live demo](examples/08-frame-render.html) · [View source on GitHub](https://github.com/brenotreviso/coded-motion/blob/main/examples/html/08-frame-render.html) |
| **09 · Library demo** | The same kind of idle and caption, made by calling the shared library instead of writing new animation code. | [Open the live demo](examples/09-library-demo.html) · [View source on GitHub](https://github.com/brenotreviso/coded-motion/blob/main/examples/html/09-library-demo.html) |
