# Coded Motion

**Learn motion graphics by writing code, then teach an AI agent to do it with you.**

This guide goes from the basics (what an animation is) to shipping a branded vertical video, made entirely with code (HTML, Canvas, GSAP, Remotion). It works for three kinds of reader:

| You are… | Start with | Then |
|---|---|---|
| **Learning it yourself** | [0 · Start here](00-start-here.md) | Chapters 1 → 7 in order, opening each example as you go |
| **A student** | [The 6-week curriculum](curriculum/README.md) | One lesson, one small project and one checklist per week |
| **An AI agent** (Claude Code, Cursor, Codex, Grok Build…) | [`AGENTS.md`](https://github.com/brenotreviso/coded-motion/blob/main/AGENTS.md) and the [`coded-motion` skill](https://github.com/brenotreviso/coded-motion/blob/main/.claude/skills/coded-motion/SKILL.md) | [11 · Agent instructions](11-agent-instructions.md) |
